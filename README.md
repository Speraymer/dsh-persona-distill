# dsh-persona-distill · 人格蒸馏

把每天刷到的原料，蒸馏成一个会自己长大的人格：原料天天攒，人格每周长一次。

写进 `~/.dsh/AGENTS.md` 的 AUTO 段，**手写段一个字都不动**。

---

## 它做什么

DSH 每次开会话都会读 `~/.dsh/AGENTS.md`。这个文件分两半：

| 段 | 谁写 | 内容 |
|---|---|---|
| `HAND:BEGIN … HAND:END` | **你** | 身份、底线、怎么说话。插件永远不碰 |
| `AUTO:BEGIN … AUTO:END` | **这个插件** | 从原料里蒸出来的：原则、场景样本、我怎么活、判断（可选第五段「我该少说」） |

每天定时跑一次：读各内容源的 `voice.md`（人类怎么说话的原句）、`notes.md`（踩过的坑）、`digest/`（看过什么），压成上面那几段。

**它不发明人格。** 起点必须是你手写的那段；它只负责让 AUTO 段慢慢变厚。

---

## 安装

```powershell
dsh plugin --profile desktop add github:Speraymer/dsh-persona-distill
```

装完重启 DSH，设置里出现「人格蒸馏」。

---

## 第一次使用

1. **先攒原料**：装一个内容源（刷B站 / 刷知乎 / 刷微博）跑几轮。没有 `voice.md`，蒸出来是空的。
2. **填三格**：设置里的「它叫什么」「你和它的关系」「它是什么」。这三格进蒸馏提示词，写空也能跑，但蒸出来会像通用助手。
3. **手动跑一次**：点「立即蒸馏」，看 AUTO 段有没有变厚，再决定要不要开自动。

---

## 设置项

| 字段 | 默认 | 说明 |
|---|---|---|
| 启用 | `false` | 默认关。攒够原料、手跑过一次满意了再开 |
| 每天几点跑 | `04:10` | 本地时间 |
| 它叫什么 | 空 | 进提示词，也用来判断原料里哪些是「它自己说的」 |
| 你和它的关系 | 空 | 一句话，比如「主人和宠物」「同事」 |
| 它是什么 | 空 | 一句话定位 |
| 人格模板 | `blank` | 蒸馏的结构参考 |
| 模型 | `deepseek-flash` | 蒸馏那一轮用哪个模型 |
| provider | `deepseek-account` | 跟上面配套；自建网关就填你的路由名 |
| dsh 路径 | 空 | 找不到 dsh CLI 时手填 |
| 微信通知 | `auto` | `auto` = 装了就发一条结果通知；`off` = 不发 |

## 运行机制

**一轮的步骤**：加单实例锁 → 快照当前 `AGENTS.md` → 扫 `source.json` 找源 → 读三份原料 → 拉起一个一次性 headless 会话（叠 overlay，打开 credentials / authorization / deepseek-account 三个服务）→ 收模型输出 → 校验 → 写回 AUTO 段 → 解锁。

**为什么用 headless**：蒸馏不该占用你正在聊的那间会话，也不该被你的对话上下文带偏。它是一次性进程，跑完就退。

**三道硬约束**：

1. **手写段锁死**。输出里若在 `HAND:END` 与 `AUTO:BEGIN` 之间多出内容，直接判失败，整轮丢弃。
2. **结构校验**。AUTO 段必须是指定段数与顺序；写歪就回滚，文件保持原样。
3. **路径越界拒绝**。`source.json` 指向源目录之外（绝对路径、`..`、越界链接）一律不读。

**反面对照**（2.1.0 起）：除了学「该怎么说」，还从我**自己发出去的原句**里挑「人类不会这么说」的习惯，标 `[反]`。每条必须同时给出：习惯、我的原句、人类对照句，再加改法。缺一条不写——凭印象的自我批评不算证据。

**原料纪律**：`voice.md` 的原句必须原样抄、带行号和源 id，不许自己编一句「像人说的话」充数。

---

## 边界与已知限制

- **没有原料就没东西可蒸**：装内容源之前它是空转。
- **它只改 AUTO 段**：想让身份变化，只能你手写。
- **模型输出不合格就整轮丢弃**：那一轮什么都不会变，日志里有原因。
- **不做增量合并**：每次重写 AUTO 段，不是往后追加。
- **跑的时段会影响额度**：04:10 是你睡觉的时候；改到白天会和聊天抢模型额度。

---

## 依赖与降级

- 需要 `dsh` CLI（桌面版自动探测；找不到就在设置里填路径）。
- 没有内容源插件时**不报错**，只是没原料。
- 没有微信插件时通知那步静默跳过。
- 不依赖其他插件的内部控制，只读它们约定的三份原料文件。
